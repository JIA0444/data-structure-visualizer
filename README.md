# 🧬 数据结构可视化 DataViz

> 让抽象的数据结构 **动** 起来 —— 导入 C 语言代码，看它一步一步执行；或选择章节，用动画看懂每一种数据结构。

**纯静态网站 · 零依赖 · 零后端**，浏览器直接打开即可使用，可一键部署到 GitHub Pages。

## 📚 内容覆盖（15 个专题 · 31 个交互演示 · 62 段 C 代码示例）

- **线性结构**：数组与顺序表（查找/插入/删除/逆序/最值/有序合并）· 链表（**头插/尾插 × 带头结点/不带头结点**、按值删除两种写法、有序插入、约瑟夫环、三指针反转）
- **栈与队列**：栈（LIFO/括号匹配/中缀转后缀/**链栈带头结点与不带头结点**）· 队列（**顺序队列/循环队列/链队列**）
- **查找与排序**：查找（顺序/二分循环/二分递归）· **10 大排序**（冒泡/选择/插入/希尔/归并/快排/堆排/计数/基数/桶）
- **树与堆**：二叉树（先/中/后/层序遍历 + **先序序列建树**）· 二叉搜索树 BST（插入/查找/最小/**删除三种情况**）· AVL 平衡树（四种旋转 + **插入自动旋转**）· 堆（建堆/堆排序）
- **图与匹配**：图算法（BFS/DFS/**邻接矩阵 BFS·DFS 实现**/Dijkstra/拓扑排序/Prim/Floyd）· 字符串匹配（朴素/**KMP**）· 哈希表（**链地址法 C 实现**/开放定址/桶计数）
- **综合工具**：代码实验室（自由导入 C 代码，12 段语言特性示例）· 复杂度速查总表

## 🖥️ C 语言解释器支持范围

```c
int / char / 指针 / struct / typedef struct / 结构体数组 / 指针数组
一维数组、二维数组 int m[2][3]、字符串 char s[] = "hello"
malloc(sizeof(struct Node)) / free / NULL / sizeof(int)
if / while / for / do-while / switch-case / break / continue / return
自定义函数 / 递归（深度≤64）/ main(void)
printf("%d %s %c %p") / scanf("%d %s") ← 数据在「标准输入」框填写
三元 a?b:c / 逗号表达式 / 位运算 & | ^ ~ << >>
++ -- += -= *= /= %= / &取址 / *解引用 / -> / . / (类型)转换
#include 自动忽略 / #define 对象宏 / 内置 strlen strcmp strcpy strcat
```

**不支持**（会给出精确行号报错）：`goto`、位域/联合体、三维以上数组、函数指针、标准库函数（除 printf/scanf/malloc/free/str*）等。

**出错也能看动画**：运行到一半崩溃（越界/除零/NULL/死循环保护）时，动画会播放到「崩溃前一步」再弹出红色错误说明，方便调试。

**保护机制**：最多执行 700 步、递归深度 ≤ 64，防死循环卡死页面。

1. **新建仓库**：在 GitHub 上创建仓库，例如 `datastructure-visualizer`；
2. **推送代码**：
   ```bash

   git commit -m "init: 数据结构可视化学习网站"
   ```

## 📖 使用建议（学习路径）

1. **入门**：数组 → 链表 → 栈与队列（重点看"指针断链重连"与"假溢出"）
2. **攻坚**：二叉树遍历 → BST → AVL（旋转）→ 堆（建堆 O(n) 为什么是 O(n)）
3. **进阶**：图三件套（BFS/DFS → Dijkstra → MST）→ KMP（next 数组）
4. **回血**：排序十连 + 复杂度速查总表，考前刷一遍

学习方法：每个专题先看「📖 知识讲解」→ 再到「🎬 动手演示」改数据乱试 → 最后在「💻 代码可视化」读/改/跑 C 代码，把实现串起来。
