📖 使用指南

1

选择章节

左侧目录或首页卡片进入任意专题，如「链表」「快速排序」。

2

动手演示

「🎬 动手演示」里改数据、点生成，观察完整动画过程。

3

导入代码

「💻 代码可视化」里写/粘贴/导入 C 代码，点运行，逐行走给你看。

4

控制节奏

用 ⏯ 暂停、⏭ 单步、进度条回放、0.25~4 倍速；快捷键：空格=播放/暂停，←/→=上一步/下一步。

🖥️ C 代码支持范围

支持 int / char、指针、struct / typedef、一维与二维数组、结构体数组、字符串、malloc / free / NULL、 if / while / for / do-while / switch、自定义函数与递归、printf / scanf（含「标准输入」框）、 三元 ?:、逗号、位运算、++ -- += & * -> 等；#include 与 #define 自动处理。 解释器记录每一步的变量、内存与指针关系，自动选择链表 / 树 / 数组 / 内存视图渲染， 运行出错也会动画播放到崩溃前一步再给出精确定位。不支持的语法（如 goto）会给出行号级中文报错。

⚠️ 说明

本站是学习辅助工具：解释器强制顺序执行、最大 600 步防死循环，适合理解算法流程；真实工程的编译与运行请使用标准 C 编译器（gcc/clang）。
